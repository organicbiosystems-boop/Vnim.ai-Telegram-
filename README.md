# VNIM.AI — бот новостей для канала @VnimAi

Бот следит за ИИ-новостями из RSS-лент, пишет по ним посты на русском (через Claude)
и решает, что с каждой новостью делать:

| Тип | Пример | Что делает бот |
|---|---|---|
| 🔴 **Срочная** | «Вышла Fable 3.5» | Публикует в канал сразу и сообщает вам обоим |
| 🟡 **Обычная** | «Ускорение локальных моделей в 5 раз…» | Присылает вам обоим с кнопками ✅ / ❌ / ✏️ |
| ⚪ **Мусор / дубль** | реклама, не про ИИ, повтор | Молча пропускает |
| 🟢 **Обычная, но бот уверен** | — | Когда бот обучится, публикует сам и сообщает вам |

В конце каждого поста — ссылка на источник и подпись **VNIM.AI**.

## Как бот учится

1. Для каждой новости Claude ставит прогноз: «с какой вероятностью владельцы её одобрят» (0–100%).
2. В подсказку Claude попадают последние 25 одобренных и 25 отклонённых вами новостей —
   так он со временем перенимает ваш вкус.
3. Бот сравнивает свои прогнозы с вашими решениями и ищет порог, выше которого вы
   одобряли ≥ 95% новостей. Нужно минимум 30 ваших решений.
4. Когда такой порог найден, обычные новости с прогнозом выше порога публикуются сами.
   Если такой пост вам не понравился — нажмите 🗑 «Удалить из канала»: это засчитается
   как ошибка, и порог поднимется (или автопубликация выключится, пока бот не научится снова).
   Не удалили — значит, одобрили.

Прогресс обучения смотрите командой `/stats`.

Кнопки у вас и у партнёра синхронизированы: если один нажал «Опубликовать», у второго
карточка обновится, и дважды пост не уйдёт.

Можно прислать боту текст или ссылку на новость — он оформит пост и пришлёт на проверку.
«✏️ Изменить текст»: пришлите новый текст (первая строка — заголовок).

## Запуск без сервера (GitHub Actions, бесплатно)

Бот запускается сам каждые ~10 минут прямо на GitHub: проверяет ленты, обрабатывает
нажатые вами кнопки и выключается. Платить нужно только за Claude API.
Нажатие кнопки срабатывает при следующем запуске, то есть с задержкой до 10–15 минут
(GitHub иногда опаздывает с расписанием).

1. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**
   и добавьте четыре секрета:

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
   | `ANTHROPIC_API_KEY` | ключ с console.anthropic.com |
   | `ADMIN_IDS` | ваш id и id партнёра через запятую (узнать — у @userinfobot) |
   | `DB_PASSWORD` | любая длинная фраза; ею шифруется база с вашими решениями. **Не меняйте и не теряйте её** |

2. Вы и партнёр — напишите боту `/start` (иначе он не сможет писать вам первым).
3. Откройте вкладку **Actions → VNIM.AI bot → Run workflow**, чтобы запустить первый раз вручную.
   Дальше бот работает сам.

База хранится зашифрованной в ветке `bot-data` — не удаляйте её.
Если на GitHub 60 дней не было никаких изменений, он может приостановить расписание и
прислать письмо — включите обратно кнопкой в Actions.

## Запуск на своём сервере (кнопки срабатывают мгновенно)

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Добавьте бота **администратором** канала @VnimAi с правом публикации и удаления сообщений.
3. Вы и партнёр — напишите боту `/start` (иначе Telegram не даст ему писать вам первым).
   Бот ответит вашим id — его нужно вписать в `ADMIN_IDS`.
4. Получите ключ Claude API на [console.anthropic.com](https://console.anthropic.com).
5. Скопируйте `.env.example` в `.env` и заполните.
6. Запуск:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

или в Docker:

```bash
docker build -t vnim-bot .
docker run -d --restart=always --env-file .env -v $(pwd)/data:/app/data --name vnim-bot vnim-bot
```

Бот должен работать постоянно, поэтому нужен сервер (любой недорогой VPS).
**Папку `data/` не удаляйте** — там база с вашими решениями, на которых бот учится.

При первом запуске бот пропускает уже вышедшие новости и дальше присылает только новые.

## Настройка

- **Источники** — файл `feeds.txt`, по одной RSS-ссылке на строку. После правки перезапустите бота.
- **Подпись** — `SIGNATURE` в `.env`.
- **Как часто проверять ленты** — `POLL_INTERVAL_MIN` (минуты).
- **Отключить автопубликацию срочных** — `AUTO_PUBLISH_BREAKING=false`.
- **Строгость обучения** — `LEARNING_MIN_DECISIONS` и `LEARNING_TARGET_PRECISION`.
- **Модель** — `CLAUDE_MODEL` (по умолчанию `claude-opus-5-5`), `CLAUDE_EFFORT` (`low` дешевле, `high` тщательнее).

## Команды

- `/stats` — статистика и состояние обучения
- `/check` — проверить ленты прямо сейчас
- `/cancel` — отменить редактирование
